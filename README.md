### Features
- 📊 Rich dashboard with animated budget tracking
- 💰 Manual expense/income logging — full control, no auto-categorization
- 🏷️ Custom categories with icons and colors
- 📈 Budgets (overall + per-category) with progress tracking
- 🔍 Powerful search, filters, and sorting in transaction history
- 💡 Deterministic insights — no AI, pure calculation
- 📉 Visual reports with pie charts and trend graphs
- 🌙 Dark / Light / System theme support
- 🔒 100% offline — no login, no cloud, no tracking, no ads
